What is CSS?

Cascading Style Sheets (CSS) is a style sheet language used for specifying the presentation and styling of a document written in a markup language, such as HTML or XML (including XML dialects such as SVG, MathML, or XHTML). CSS is a cornerstone technology of the World Wide Web, alongside HTML and JavaScript.

CSS is among the core languages of the open web and is standardized across web browsers according to W3C specifications. Previously, the development of various parts of CSS specification was done synchronously, which allowed the versioning of the latest recommendations. You might have heard about CSS1, CSS2.1, or even CSS3. There will never be a CSS3 or a CSS4; rather, everything is now just "CSS" with individual CSS modules having version numbers.

Why you need to learn CSS?

Learning CSS (Cascading Style Sheets) is essential because it transforms raw text and structure into a beautiful, functional, and user-friendly digital experience. While HTML acts as the skeleton of a website, CSS serves as the design, layout, and visual presentation layer.

CSS in Modern Web Development

CSS handles the presentation layer of a website. Here is exactly what it can do:

Visual Styling & Branding

  • Typography: Change fonts, sizes, letter spacing, and line heights.
  • Color Schemes: Apply colors to text, borders, backgrounds, and links.
  • Decorations: Create gradients, drop shadows, rounded corners, and transparency.

Layout & Positioning

  • Grid Systems: Align items into complex rows and columns using CSS Grid.
  • Flexible Box: Stack and distribute elements horizontally or vertically with Flexbox.
  • Spacing Management: Control gaps between elements using padding and margins.
  • Element Placement: Pin menus to the top or layer items on top of each other.

Device Responsiveness

  • Screen Adaptation: Resize and reshuffle content to fit mobile, tablet, and desktop screens.
  • Print Optimization: Hide sidebars and change fonts automatically when a user prints the page.

Motion Interaction

  • Hover States: Change button colors or enlarge images when a cursor rolls over them.
  • Smooth Transitions: Fade colors or slide sidebars in gently instead of snapping instantly.
  • Keyframe Animations: Create continuous moving elements, spinning loaders, or bouncing icons.

Performance and Control

  • Global Updates: Change a color in one stylesheet to instantly update thousands of webpages.
  • Dark Mode: Toggle between light and dark themes using a user's system preferences.

CSS Syntax

In order to use CSS you must use the appropriate syntax. The typical CSS syntax includes the selector and the declaration block. Take a look at the image below:

Break Down of Components:

  • Selector: Points to the HTML element you want to style (e.g., h1, p, .class-name, #id-name).
  • Declaration Block: The entire package of styles wrapped within curly braces { }.
  • Declaration: A single styling instruction pairing a property and a value, separated by a colon :.
  • Property: The style attribute you want to change (e.g., color, font-size, margin).
  • Value: The specific configuration assigned to the property (e.g., red, 16px, center).
  • Semicolon (;): Separates multiple declarations inside a single block.

Example:

Here is an example of CSS code that changes the color and font size of h1 element.

h1 { color: blue; font-size: 24px; }

Syntax Quick-Rules

  • Case Insensitivity: CSS properties and values are case-insensitive by default.
  • Whitespace: Browsers ignore extra spaces, but formatting with indentation improves readability.
  • Grouping Selectors: Style multiple elements at once by separating selectors with a comma (e.g., h1, p { color: gray; })

How to Add CSS to HTML

  • Inline CSS: Using the style attribute directly on HTML elements.
  • Internal CSS: Writing styles inside a <style> tag in the HTML head.
  • External CSS: Linking an independent .css file using the link tag.

Which Method Should You Use?

While all three methods work, External CSS is the industry standard and the highly recommended approach for modern web development. It keeps your HTML clean, improves website loading speeds, and allows you to manage the design of an entire multi-page website from a single, centralized file. Use inline styles only for quick troubleshooting and internal styles for small, single-page projects.
